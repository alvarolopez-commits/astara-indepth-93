# In Depth #92 — build

Regenerates `index_92.html` from the docx (verbatim text), the Excel (chart data) and the files in this folder.
Same pipeline as #91, with the docx in place of the PDF. Run from the project folder:

```bash
python -X utf8 _build/docx_paras.py DATA/Charging_vs_Fuel_InDepth_Content.docx _build/paras.json
python -X utf8 _build/prep_data.py DATA/Charging_vs_Fuel_InDepth_Data.xlsx _build/data.json
python -X utf8 _build/build92.py _build .
```

`paras.json` and `data.json` are kept, so the last command alone rebuilds the page.

- `body92.html` — page structure; `{{s1p1}}`-style markers are replaced with the docx paragraphs; `[[...]]` blocks are generated by the build (key figures, sources, cover motif, icons).
- `style92.css` — the single stylesheet (sections 1–6 from #91; section 7 holds the #92 chart components). Type: Orbitron for display, Inter for body text, numbers and UI (tabular figures only inside charts).
- Flag tiles: `prep_data.py` writes a market → flag code map (`flags` in `data.json`); `app92.js` draws them in chart rows, the map list and tooltips; `[[FLAGS:..]]` in the body draws them in the fuel-station list.
- `app92.js` — charts V02–V09 and interactions; `/*__DATA__*/` is replaced with `data.json`.
- `prep_data.py` — reads the Excel by column header; ND becomes null (never zero); cross-checks sheets 03, 05, 08 and 09.
- `build92.py` — writes the page and checks that every docx block appears exactly once and unaltered, apart from the edits listed in `EDITS` (exit code 1 otherwise).

Editorial edits applied on top of the docx (all in `build92.py`):
- `[EXT: ...]` source tags removed from the running text (sources go to captions and the Sources list).
- Notes addressed to the designer removed: "and the piece should say so plainly" (s6p1), "and the piece should not guess a cause" (s6p2), "(source Excel)" (s7b2).
- The editor's internal workbook is left out of the public Sources list.

# In Depth #93 — build

Same pipeline and look as #92, with the #93 docx and Excel. The #92 files stay in this folder; the #93 ones carry a `93` suffix.
Run from the project folder:

```bash
python -X utf8 _build/docx_paras93.py DATA/Most_Efficient_Mover_InDepth_Content.docx _build/paras93.json
python -X utf8 _build/prep_data93.py DATA/Most_Efficient_Mover_InDepth_Data.xlsx _build/data93.json
python -X utf8 _build/build93.py _build .
```

`paras93.json` and `data93.json` are kept, so the last command alone rebuilds `index_93.html` and `index.html`.

- `body93.html` — page structure; `{{s1p1}}`-style markers are replaced with the docx paragraphs; `[[...]]` blocks are generated by the build (cover art, champions strip, sources, icons).
- `style93.css` — the #92 stylesheet plus section 10 (#93 components: champions strip, lift figure, equation, free-scale rows, size line, paired panels).
- `app93.js` — charts V01–V09; `/*__DATA__*/` is replaced with `data93.json`. D3 is used for the size line only.
- `prep_data93.py` — reads the Excel by column header; ND becomes null (never zero); checks that the Wh columns agree with COT (75 kg per passenger, 1 t per tonne-km) and that a mover has the same COT on every sheet.
- `build93.py` — draws the two cover compositions (wide and stacked), writes the page and checks that every docx block appears exactly once and unaltered, apart from the edits listed in `EDITS`, that the chapter titles equal the docx headings and that the excerpt is literal (exit code 1 otherwise).

Editorial edits applied on top of the docx (all in `build93.py`):
- `[EXT: ...]` source tags removed from the running text (sources go to captions and the Sources list).
- References to the editor's files removed: "in Appendix B and in the Excel" (how4) and "in sheet 10_Formula" (s1p2).
- The editor's workbook entries are left out of the public Sources list (27 of the 29 Appendix B entries are listed).
- Not published: the designer's opening note, the visual notes, Appendix A and Appendix C.
